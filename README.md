# StudyMate AI

An agentic study assistant: upload your notes (PDF, DOCX, PPTX, or paste text) and
get a verified summary, flashcards, and an MCQ quiz — generated by a small team of
specialized agents, not one generic prompt. Wrong quiz answers trigger an adaptive
loop that re-explains the specific weak concept, drills it with new flashcards, and
re-quizzes you, before honestly flagging concepts that need a different resource.

You can also upload photo(s) of a previous year question paper (PYQ) instead of
notes — StudyMate reads the questions with Gemini's vision input, builds study
material around the topics they test, and writes a model answer plus "what to add
for extra marks" hints for every question.

Every concept's explanation is split into what's **faithfully drawn from your own
notes** versus what's **supplementary teaching content** added to fill gaps — the
two are never blended, so you always know which parts came from your material and
which parts are the AI teaching beyond it.

Two independent controls tune every generated document: **Explanation style**
(Simple / Standard / Technical — vocabulary and language complexity) and **Depth**
(Overview / Standard / Deep dive — how much content and nuance is covered). They're
deliberately separate so, e.g., a postgraduate student new to a subject can pick
Simple + Deep dive: plain language, but full depth, not a shallow summary.

Anytime, download a self-contained, offline HTML study pack styled like a small
ebook — carry it with you, no server needed.

## Why not just use ChatGPT?

- **Independent verification, not self-grading.** Content is generated with Gemini,
  but checked for groundedness against your actual notes by a *different* model
  (Groq) — so the system isn't just trusting its own generations.
- **Diagnostic quiz distractors.** Wrong MCQ options are designed to represent
  specific misconceptions, so *which* wrong answer you pick tells the system
  (and you) what you actually misunderstood — not just that you got it wrong.
- **A capped, honest adaptive loop.** Weak concepts get re-explained, drilled, and
  re-tested — up to 3 rounds. After that, the system checks for a prerequisite gap
  once, then explicitly tells you to seek a different resource, rather than
  pretending infinite AI regeneration guarantees understanding.
- **Shared concept vocabulary.** All agents tag content against the same
  concept list (extracted once by the Orchestrator, plus anything you add
  manually), so weak-spot tracking is precise, not vague.

## Architecture

- **LLM:** Gemini (generation agents), Groq (independent Verifier agent)
- **App:** Streamlit — single process, no separate backend
- **Storage:** SQLite
- **Export:** Jinja2-rendered single-file HTML with client-side quiz grading

```
agents/            orchestrator, summarizer, flashcard_maker, quiz_maker, verifier, pyq_solver
services/          db.py, gemini_client.py, groq_client.py, note_parser.py,
                   pipeline.py, adaptive_loop.py
export/            html_template.html, export_builder.py
app.py             Streamlit entrypoint
```

## Setup

```bash
pip install -r requirements.txt
cp .env.example .env
# add your GEMINI_API_KEY and GROQ_API_KEY to .env (both have free tiers)
streamlit run app.py
```

## Notes

- The offline HTML export's built-in quiz grades instantly in the browser for
  casual revision, but does **not** sync results back into the app — the adaptive
  loop only runs on quiz answers given inside the live Streamlit app.
- SQLite database is stored at `data/studymate.db` (gitignored).
